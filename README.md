🔗 **Live site:** [https://quantlover.github.io](https://quantlover.github.io)

## Site Map

| Page | Description |
|------|-------------|
| **Home** | Hero summary, key statistics, affiliations |
| **About** | Research identity, methodology, technical skills |
| **Projects** | Selected funded research projects |
| **Publications** | Peer-reviewed scholarship |
| **Teaching & Talks** | Invited lectures, conference presentations, courses |
| **CV** | Education, appointments, awards; downloadable PDF |
| **Contact** | Email, phone, GitHub |

## Tech Stack

- Pure HTML5 / CSS3 / Vanilla JS — zero dependencies, zero build step
- Google Fonts: DM Serif Display + DM Sans + DM Mono
- IntersectionObserver-based scroll animations
- Responsive: desktop → tablet → mobile

## Deployment

1. Clone or fork this repository as `quantlover.github.io`
2. Push to `main` branch
3. Enable GitHub Pages (Settings → Pages → Source: `main` / `root`)
4. Replace `CV_Chi_Chang.pdf` with your actual CV file for the download button

## Customization Notes

- All colors are CSS variables in `:root` — one-line changes propagate site-wide
- Add your actual `CV_Chi_Chang.pdf` to the repo root for the CV download button to work
- Publications and projects are static HTML — update directly in `index.html`, or migrate to a JSON data file with JS templating
